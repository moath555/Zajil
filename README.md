# Zajil Discord Bot

بوت زاجل يرسل رسائل خاصة للأعضاء من خلال زر في السيرفر، مع إعدادات مقفلة على المالك والمصرحين فقط.

## التشغيل

1. انسخ ملف `.env.example` إلى `.env`.
2. حط توكن البوت وايدي حسابك:

```env
DISCORD_TOKEN=توكن_البوت
OWNER_IDS=ايدي_حسابك
```

3. من Discord Developer Portal فعل:

- Message Content Intent
- Server Members Intent

4. شغل:

```powershell
npm start
```

أو افتح `start.bat`.

## أمر الإعدادات

الأمر الافتراضي:

```text
%settings
%اعدادات
```

إذا غيرت البرفكس إلى `!` يصير:

```text
!settings
!اعدادات
```

## الموجود في الإعدادات

- برفكس البوت.
- إضافة/إزالة مصرح بالمنشن أو الايدي.
- عرض المصرحين.
- تغيير اسم البوت والافتار والبنر.
- تغيير حالة البوت.
- صورة عرض زاجل.
- شكل زر الإرسال.
- إرسال القائمة في شات محدد.
- الكلمات الممنوعة.
- حظر عضو من إرسال زاجل لمدة محددة أو بشكل دائم.
- إنشاء لوق مخفي باسم `zajil-log`.
- عرض صور وGIF وفيديو وملفات الزواجل داخل اللوق، مع علامات إرسال/رد/إعجاب واضحة.
- تسجيل الإعجابات في امبيد وردي داخل اللوق.
- تفعيل/تعطيل الإرسال كظاهر أو مجهول وزر اللايك والرد.
- لون الامبيد.
- رسالة وإيموجي زاجل.
- شكل زر اللايك وشكل زر الرد.
- رسالة إشعار اللايك ورسالة الرد على زاجل.
- إرفاق صور وفيديو وGIF وملفات من نافذة زاجل.
- الرد من نفس الخاص بنص أو مرفقات، مرة واحدة فقط لكل زاجل.
- اختيار طريقة كتابة الرد: نافذة أو نفس الشات الخاص.
- تعديل رسالة طلب الرد ورسالة إشعار اللايك بالكتابة في الشات.

## أوامر الحظر

هذه الأوامر للمالك والمصرحين فقط، وتستخدم البرفكس الحالي:

```text
%حظر @member
%block @member
%unblok @member
%unblock @member
%الغاء حظر @member
%إلغاء حظر @member
```
